📋 How to Use This Testcase Generator

  1. Select a Sample Story: Click on any sample user story from the "Sample Banking Stories" section below or paste your own user story.
  2. Copy the Story: Use the copy button to add the story to your clipboard for easy sharing.
  3. Open Langflow Chat: Click the chat icon in the top-right sidebar to open the AI chat assistant.
  4. Generate Test Cases: Paste your user story into the Langflow chat and ask for test case generation.
  5. Review Output: The AI will generate comprehensive test cases that appear in the chat window.
  6. Copy Results: Use the "Copy Chat Output" button to copy all generated test cases.
  7. Clear History: Click "Clear Chat" to reset and start a new test case generation session.
