User Story Review Agent
AI-powered review for Jira User Stories
⚡ One-time setup — open a terminal in the project folder and run:  node proxy.js  → starts a local CORS proxy on port 8080. No npm install needed — pure Node.js. Leave the terminal open while using this page.
📖
How to Use
1

Click Open Review Agent in the top-right corner to open the chat panel.

2

Select a Jira user story from the dropdown, or paste your own user story text.

3

Click Send for Review and wait for the AI to analyse your user story.

4

Read the detailed review, copy it, or clear the chat to start a new review.
